# International Academy calendar tracker

This repo contains a single-file static website designed for GitHub Pages.

Files:
- `index.html` — the full single-page calendar tracker
- `.github/workflows/pages.yml` — deploys the repo to GitHub Pages via GitHub Actions

To publish:
1. Push this repo to GitHub.
2. Open GitHub → Settings → Pages.
3. Set Source to `GitHub Actions`.
4. Save.

The page is fully offline-capable, uses no database, and auto-detects the current system date.
